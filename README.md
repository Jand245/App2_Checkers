# App2_checkers

A Flutter checkers game being built one approved feature at a time.

## Current phase

The starter shell includes the application theme, game screen, and a placeholder
for the board. Gameplay has not been added yet.

## First-time setup

This project belongs in the `4330/App2_checkers` directory. This workspace does
not include Flutter's generated platform folders. From the `App2_checkers`
directory, run:

```sh
flutter create .
flutter pub get
flutter run
```

`flutter create .` generates the Android and other platform scaffolding while
keeping the app code in `lib/main.dart`.
